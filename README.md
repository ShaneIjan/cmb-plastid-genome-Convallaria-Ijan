The complete chloroplast genome of *Convallaria majalis* was downloaded from NCBI RefSeq in both **FASTA** and **GenBank (full)** formats. The FASTA file was uploaded to Galaxy, confirmed as FASTA format, and analyzed using the **FASTA Statistics** tool.

The RefSeq annotation contains 132 annotated gene entries, including 86 CDS entries, 38 tRNA genes, and 8 rRNA genes. Introns are present, while no pseudogene is explicitly annotated in the downloaded RefSeq record. Several genes are duplicated within the inverted-repeat regions.

Notable observations include a genome length of 162,198 bp, a 37.88% GC content, a single complete sequence record, and the typical LSC-IR-SSC-IR plastome organization.
